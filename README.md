# Edris Hanifi — Simple Portfolio

A lightweight, responsive one-page developer portfolio inspired by modern editorial/Dribbble-style portfolio layouts.

## Run it
Open `index.html` in a browser, or serve the folder with any simple local web server.

## Customize
- Replace the sample project titles/descriptions in `index.html`.
- Update the email link in the Contact section.
- Add your real GitHub/LinkedIn/WhatsApp links.
- Replace `assets/profile.jpg` with another profile photo if needed.
